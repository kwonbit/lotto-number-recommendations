# LottoPick — 로또 번호 추천

React와 Vite로 만든 반응형 로또 번호 추천 웹 애플리케이션입니다.

## 주요 기능

- 1~45 사이에서 중복 없이 6개 번호 무작위 생성
- 1개, 5개, 10개 조합 선택
- 번호 구간별 색상 표시
- 추천 조합 클립보드 복사
- 현재 접속 중 최근 추천 기록 표시
- 모바일, 태블릿, 데스크톱 반응형 레이아웃
- 키보드 포커스 표시 및 동작 줄이기 설정 지원

## 실행 방법

Node.js가 설치되어 있는지 확인한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드 및 미리보기:

```bash
npm run build
npm run preview
```

## 기술 스택

- React
- Vite
- CSS Media Queries

## 참고

번호는 무작위로 생성되며 당첨을 보장하거나 당첨 확률을 높이지 않습니다. 추천 기록은 현재 페이지 세션에서만 유지됩니다.
